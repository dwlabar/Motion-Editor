# Local design fonts

Open Sans (400/700), Inter (400/700), and Syncopate (400/700) were obtained from Google Fonts on 2026-09-15 and are served locally by `src/styles/_fonts.scss`.

- Inter and Open Sans: SIL Open Font License; see `inter-OFL.txt` and `opensans-OFL.txt`.
- Syncopate: Apache License 2.0; see `syncopate-LICENSE.txt`.

Sources: https://fonts.google.com/ and the corresponding family license files in https://github.com/google/fonts.
